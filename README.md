## 演示

1. 叶老师 → 课堂大屏、抽查、目标、花名册、小队。可添加/改名/删除学生、调座、改班级目标、全班基础达标、发放集体奖励、荣誉结算、重置演示。点座位「未完成 / 特别突破」。走神提醒只出老师 toast。
2. 王老师 → 仅课堂大屏与抽查。可上课中、核验、未完成、特别突破。不能改花名册、改班级目标、发放集体奖励、删除学生、重置演示。
3. 林小舟主页：轻点 / 抚摸 / 喂食均 0 养成积分，都会写 lastCare、清零想念值。久未照料出现表情 missSoft 与文案「有点想你」，不会病死。外形按成长点分幼 / 少 / 成。
4. 班级周 KR ≥ 80% 后由班主任发放集体奖励。林小舟目标含「订正」，特别突破后解锁「反思之眼」。
5. 荣誉橱窗本周最多 6 席（历年累计不占坑），连续上墙 ≤ 2。学习闭环成就只计已入账 / 超时入账的申报。驳回不占当日申报条数。超时入账记原日期，不吃次日入账帽。
6. 个人贡献只看确认过的努力勾选。课堂若仍有 classScores，随周 id 清零，不公开累计分。

不设末位小组 KR，不加云同步。
