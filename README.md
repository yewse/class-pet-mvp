# 班级宠物养成

离线中文教室：周目标勾选需证据并确认、每日心情、课堂大屏。存储键 `class-pet-mvp-v10`（会读 v9）。

登录：叶老师 / 林小舟 / 陈安安 / 林妈妈。重置演示用老师账号。

## 演示

1. 林小舟 → 宠物主页：写一句中文证据，点「打钩」。进度点变待确认，宠物不长、班级条不动。
2. 退出，陈安安登录 → 宠物主页「同学待确认」点「确认」（或互访页确认）。或叶老师课堂大屏点林小舟座位 → 核验「确认」。
3. 确认后林小舟成长 +8（当日首次），班级进度条上升。
4. 林小舟、陈安安各选今日心情「雨」。叶老师课堂大屏顶部见晴/云/雨人数，横幅「班级有点累，先看看大家」，宠物表情疲惫。
5. 老师「目标」周视图：班级周 KR 低于 50% 时宠物休眠（闭眼、变暗），文案「目标没到，全班一起复盘，不是谁的错。」不是生病/死亡。
6. 大屏手写板按钮是「核验 / 确认 / 推进」，本课次数上限仍为 +6 / −3，不出现加减分字样。

不设末位小组 KR，不加云同步。
