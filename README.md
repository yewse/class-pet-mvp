# 班级宠物养成

离线中文教室：例外式全班基础达标、周目标努力勾选、集体奖励。存储键 `class-pet-mvp-v11`（会读 v10 / v9）。

登录：叶老师 / 林小舟 / 陈安安 / 林妈妈。重置演示用老师账号。

## 演示

1. 叶老师 → 课堂大屏：点「全班基础达标」。全班（无例外）各得今日基础勾，计入班级周 KR。周一四人齐达标即为 100%。
2. 点林小舟座位：只会出现「未完成」（从今日基础里排除/撤销）或「特别突破」（有待确认证据则确认；否则写一句备注再确认个人 KR）。
3. 班级周 KR ≥ 80% 后，大屏或「目标」出现「发放本周集体奖励」，优惠默认「周五少一项作业」。学生主页能看见，不会自动删作业。
4. 林小舟目标含「订正」，老师给一次特别突破/确认勾选后，解锁头饰「反思之眼」（不可购买）。回学生主页可戴上。
5. 个人贡献只看确认过的努力勾选，没有考试分、没有宝箱或随机暴击。

不设末位小组 KR，不加云同步。
