# 班级宠物 · 种子/A 轮融资备忘

**叙事口径**：约人民币 5,000 万（种子到 A 的叙事额度，非承诺估值）。  
**产品阶段**：班级级习惯+学业闭环 MVP（演示/规则已冻结，**无对外付费合同、无试点营收、无客户 logo**）。  
**文档性质**：董事会可读备忘。下文凡带 **【假设】** 的数字均为规划假设，**不是事实、不是承诺**。

---

## 1. 问题

初中班主任同时扛三件事：作业闭环、日常习惯、家校沟通。现有工具要么是「拍照交作业 / 打卡」——无情感留存；要么是「班级排行 / 积分竞赛」——短期有效、长期制造羞辱与家长投诉。

学生侧：作业订正、自测、参与没有稳定的**日循环理由**。家长侧：只看见分数与投诉，看不见过程。学校侧：买了一堆 App，没有可审计的过程数据，也买不起「再刺激一次排名」的舆情风险。

缺口不是再做一个作业 App，而是：**把学业过程变成可养护、可审计、不可羞辱的班级日常。**

---

## 2. 为什么是现在

- **双减后学校采购逻辑变了**：买的是减负、合规、可解释的过程管理，不是再加一层应试军备。
- **班主任数字化已发生**：家校群、作业收集已普及；缺的是**不增加教师批改负担**的闭环。
- **虚拟宠物/养成心智成熟**：日养护成本低、情感绑定强，适合初中日常而非开放世界游戏。
- **过程数据开始被要**：区校督导要「订正率 / 参与率 / 习惯连续性」，不要全班公开名次。

窗口是：**学校愿意为「无羞辱的过程系统」付费，学生不再被要求付费养学。**

---

## 3. 产品

两层，一套账本。

### 3.1 班级宠物（学生 / 家长日循环）

每生一只宠物（狐/猫头鹰/水獭/猫/犬/兔）。学业过程换成可养护的积分：作业质量、订正闭环、自测对照、课堂参与。积分有**日赚上限 / 日耗上限**，防止肝、防止刷。

同伴复核 + 教师抽检队列（有上下限），超时有效自动入账。小队周积分、荣誉墙有人数与连庄上限。探访/表情/加餐是弱社交，不是 PK。家长只看自己的孩子与过程，不看全班名次。

### 3.2 学校 SaaS（付费面）

面向班主任与教务：抽检队列、积分账本、荣誉发放约束、班级周报（过程指标，非羞辱榜）。后续校级：多班开通、教师账号、学期归档、区级只读督导视图。

**学校买的是：可审计的过程操作系统 + 学生愿意每天回来的宠物循环。学生不买皮肤氪金。**

## 4. 冻结规则（不可为融资改口）

| 规则 | 含义 |
| --- | --- |
| **无班级羞辱榜** | 不做全班学业/积分公开排名；荣誉墙有容量与连庄上限，禁止同一人垄断。 |
| **学生免费** | 学生端零付费、无内购、无家长代充。皮肤/坐骑用过程积分兑换。 |
| **学校付费** | 唯一商业化：学校（或区）按年订阅 SaaS。 |
| **日上限** | 赚/花/申报/复核均有日帽，反肝、反刷分。 |
| **可抽检** | 同伴事实/存疑 + 教师队列；存疑不自动入账。 |
| **家长免打扰** | 家长可 DND；默认只看自家孩子。 |

以上是产品宪法。任何「加排行榜就能增长」的建议直接否决。

## 5. 单位经济（草图，全部【假设】）

口径：一所普通初中，约 24–36 个教学班，1,000–1,800 名学生。【假设】

| 项 | 【假设】 |
| --- | --- |
| 校年 ARPU（单校订阅） | 8–15 万人民币/年（按班数阶梯；含教师席位与学期归档） |
| 区打包折扣 | 名单校价 6–7 折，换区级统一开通与续费 |
| 落地 CAC（首年，含实施/培训/班主任陪跑） | 3–6 万/校 |
| 年服务成本（托管、支持、内容运营） | 1.5–3 万/校 |
| **毛贡献（稳态年）** | 约 5–10 万/校 |
| **回收期** | 约 6–14 个月（视是否走区标、是否自建实施团队） |

不靠学生 LTV，不靠广告。续费锚点是：**班主任周使用 + 订正闭环可见 + 零舆情事故。**

敏感度：若 ARPU 落到 5 万以下且 CAC 不降，回收期超过 18 个月，叙事不成立——应减实施厚度或只做区标，而不是向学生收费。

## 6. 三年扩张路径

**班 → 校 → 区。禁止跳级卖「全市 App」。**

| 年 | 动作 | 【假设】规模 |
| --- | --- | --- |
| Y1 | 班主任口碑。单班跑通日循环与抽检。同校复制到年级。 | 3–8 所深度校，约 80–200 班 |
| Y2 | 校级合同（学年订阅）。教务看板、多班开通、学期归档。 | 40–80 校，ARR 【假设】400–800 万 |
| Y3 | 区级只读督导 + 统一采购。仍无全班羞辱榜。 | 2–5 个区，200–400 校，ARR 【假设】2,000–4,000 万 |

5,000 万融资对应的是：**把 Y1 规则跑成可复制实施包，支撑 Y2 校级销售机器**，而不是买量。

## 7. 护城河（可积累，不可吹）

1. **心理规则资产**：无羞辱榜、日帽、荣誉连庄限制、家长 DND——是合规与留存的同一套设计，后来者「加排行」会先死在舆情。
2. **每日宠物循环**：养护、表情、弱社交探访，把订正/自测绑在「今天要照顾它」上，而不是再推一次通知。
3. **结果与过程数据**：订正闭环、有效申报、抽检一致率、连续养护天数——形成学校续费与区级督导都读得懂的账本。数据不出校、不卖。

这三件事叠在一起才是壁垒。单做一只可爱宠物或单做一套积分后台，都不够。

---

## 8. 合规

- **未成年人**：学生免费；无充值、无随机抽奖付费、无强制社交、无诱导超时使用（日帽即产品化的防沉迷）。
- **个人信息**：最小必要；班级内账号；家长只绑定自己的孩子。默认校内部署或校授权租户，**不做跨校社交图谱**。
- **教育内容**：不替代教材、不售卖题库广告、不承诺提分。对外口径永远是过程管理，不是提分神器。
- **采购与资金**：To 学校/区财政或课后服务合规科目；不向学生收取任何费用，避开「校园贷/家长拼单」红线。
- **内容安全**：同伴复核只判事实/存疑，不做公开批斗墙。

## 9. 风险

| 风险 | 为什么致命 | 对策 |
| --- | --- | --- |
| 班主任不打开 | 没有日活就没有宠物循环 | 抽检队列必须比现有作业群更短；超时自动入账 |
| 学校要「可见排名」 | 一改口，护城河与合规同时塌 | 合同与产品写死；只提供过程分布，不提供名次 |
| 区招周期长 | 烧完实施费还没回款 | Y1 只做校级现金；区标当期权 |
| 被大厂作业 App 抄宠物皮 | 皮能抄，规则+数据账本难在一季抄完 | 把规则做成实施包与学期数据资产 |
| 同伴复核变成霸凌 | 与羞辱榜同类舆情 | 存疑私密、抽检、日复核帽、教师一键撤销入账 |
| 提分承诺蔓延 | 监管与口碑双杀 | 销售话术冻结，违规即停单 |

## 10. 18 个月里程碑（数字均为【假设】）

**资金用途（【假设】拆分，对应约 5,000 万叙事）**：产品与数据账本 ~35%；实施与班主任成功 ~25%；校级销售（不含投放买量）~20%；合规/安全/私有化交付 ~10%；缓冲 ~10%。

| 月 | 必须交出的东西 | 【假设】数字 |
| --- | --- | --- |
| 0–6 | 生产级班级循环：领养、申报、复核、抽检、账本、宠物养护、家长只读。无公开排名。 | 8–15 个真实班完成 ≥6 周连续使用；周活跃学生 **【假设】** ≥60% |
| 6–12 | 校级 SaaS：多班、教师席位、学期归档、合同与开票。实施包可被非创始人交付。 | 6–12 份**付费或明确采购意向**的校年合同；校 ARPU 落在 8–15 万区间（【假设】） |
| 12–18 | 同城/同区复制；第二学科或第二年级不拆规则。开始区级只读试点（可失败）。 | 累计 25–40 校；ARR **【假设】** 250–500 万；净收入留存 **【假设】** ≥90%；重大舆情事故 = 0 |

**明确不是里程碑的东西**：下载量、学生付费率、全班排行点击、任何「已服务 XX 万学生」的宣传数字——在出现真实合同之前全部禁止对外使用。

## 11. 本轮要证明的一句话

用学校的钱，养活一个**学生愿意每天回来、班主任抽检负担下降、全班没有羞辱榜**的过程系统；18 个月内用真实校合同证明回收期，而不是用故事证明爱心。
